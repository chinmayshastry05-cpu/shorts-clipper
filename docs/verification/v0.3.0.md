# v0.3.0 verification (18 Oct 2026)

## What changed
- Tkinter GUI replaced with a local web UI (stdlib `http.server` + single-page
  Magic UI-style front end). Reason: the standalone CPython used by the
  AppImage ships Tk built `no-xft`, so Tkinter renders bitmap core fonts on
  every Linux desktop — a modern UI is impossible there. The browser supplies
  fonts, rounded corners, animations. No new runtime deps (customtkinter and
  tkinterdnd2 removed; Pillow stays for the preview frame).
- Whisper default `tiny` → `small` (tiny crashed on Hindi word alignment;
  base mis-detected Hinglish as Urdu). Segment word pass forces the language
  detected on the full audio; a word-alignment crash falls back to
  phrase-timed captions instead of failing the run.
- Renders are atomic (`.part` file moved into place) and an existing output
  is validated (non-empty + ffprobe-able) before reuse.
- Captions: outline/shadow raised (cinematic 9/6, karaoke 7/5).
- Server quits when the page closes (heartbeat watchdog), never mid-job.

## Tested
- `pytest`: 38/39 pass. The one failure
  (`test_editing.py::test_detect_face_returns_none_without_faces`) also fails
  on unmodified v0.2.1 with opencv 5.x — pre-existing, env-related
  (requirements pin `<5`; test env here had 5.0.0 installed without the pin).
- Live e2e, source install: 38 s speech video → prepare (83 words) → preview
  frame (540×960) → render → download: 1080×1920 H.264+AAC, 30.0 s. Caption
  outline verified readable on a bright-yellow frame (screenshot checked).
- Live e2e, AppImage (269 MB, sha256
  69dd9a76e6df438dfe87f9694accff025d7b2e400c87aea652135efb20dac986):
  CLI `--help` works; server boots; prepare through the API works; UI
  screenshot verified (dark + light themes, loaded preview, busy state).
- Caption drag: new implementation positions the caption from the pointer's
  absolute position inside the preview (`(clientY-rect.top)/rect.height`,
  clamped 5–95%); the v0.2.x incremental-delta bug class is gone by
  construction.
- YouTube download from this datacenter IP is bot-checked (403), unchanged
  from v0.2.x; local-file path used for e2e instead.
